# Calculadora Minimalista

## Projeto simples desenvolvido para praticar manipulação de DOM e lógica básica com JavaScript puro. 
O foco foi criar uma interface limpa, funcional e com um design escuro moderno.Tecnologias utilizadas

    HTML5

    CSS3

    JavaScript

# Como executar

    Baixe o arquivo index.html.

    Abra o arquivo em qualquer navegador.
